# gnx-mods-and-tools
Mods and Tools available for the GNX platform.

# Version Updates

When updating, it is highly recommended to delete the existing folder first.  This is because some updates remove files, and copying and replacing won't automatically remove these old existing files.

E.g., in Shiny Peasant's case, v1.0->v1.1 excludes 12k sprite files that won't be automatically replaced.
