#Intro
Gobs,

Here is a GNX mod adding a new class "Shiny Cleric" using the base sprite structure (i.e., she comes in three flavors).

Clerics are still in the game.  Shiny Clerics are a very rare variant.
Shiny Clerics spawn in the Forest location (with all the other Clerics), even rarer in lvl 3 Village, Mountain, Castle.  (Bump weight up +100 in classes.json if you want more to spawn)
All girls get a palette swap, as is shiny tradition.
One girl has Hathor's boobs, but still has the regular body frame.  (Including a lot of sprite editing for that.)
One girl can't help but keep her head down in Behind.
Always 5 stars.
Has the same offspring as a regular cleric.  At 666 births, also functionally convenient if you're looking for a specific Cleric spawn.
Does appear in the shop, though more often than I'd like.
Fully compatible with other GNX mods.

Install:

Follow the usual instructions for GNX:
https://github.com/MovaFlow/GNX

Unzip this shiny_cleric.zip file and add the uncompressed "shiny_cleric" folder into your GNX_Mods folder.

Let me know if you see any suggestions, issues, bad frames, garbage drawing, etc.
