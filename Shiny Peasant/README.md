Gobs,

Here is a GNX mod adding a new class "Shiny Peasant" using the base sprite structure (i.e., she comes in three flavors).

Peasants are still in the game.  Shiny Peasants are a very rare variant.
Shiny Peasants are in all Village levels, even rarer in lvl 3 Forest, Mountain, Castle.  (Bump weight up +100 in classes.json if you want more to spawn)
It's mostly a palette swap, as is shiny tradition.  Except tentacles hate gold hoop jewelry...
Always 5 stars.
Has the same offspring as a regular peasant.  At 666 births, also functionally convenient.
Does appear in the shop, though more often than I'd like.
Not every body sprite is available yet in GNX to edit.  E.g., gob drinking is to edit... (yet?)
Has more strips than it needs in folder and in json file as it includes 30 unhooked monster interactions and both regular/smol base bodies.
As more GNX features become available, I may come back to make edits.

Install:

Follow the usual instructions for GNX:
https://github.com/MovaFlow/GNX

Unzip this shiny_peasant.zip file and add the uncompressed "shiny_peasant" folder into your GNX_Mods folder.
